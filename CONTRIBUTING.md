# Contributing

This is my personal portfolio and production application, licensed under PolyForm Noncommercial. It is not open to feature requests or design changes, since the site reflects my own personal choices rather than a shared project. Bug reports are welcome.

## What belongs here

- Something broken on the live site (a page that errors, a broken link, incorrect content)
- A genuine security issue (see [SECURITY.md](SECURITY.md) instead of an issue)
- A typo or factual correction

## What does not belong here

- Feature requests or suggestions for new pages, sections or functionality
- Design, layout or styling opinions
- Requests to reuse or fork this code beyond what the [licence](LICENSE) already permits

## Reporting a bug

Open an issue with:

- Which page or route
- What you expected versus what happened
- Steps to reproduce, if not obvious
- Screenshots or console output, if relevant

## Pull requests

Pull requests are only accepted for the bug categories above. Anything else is likely to be closed without merging, not out of rudeness, just because this repository is not run as an open collaborative project.
