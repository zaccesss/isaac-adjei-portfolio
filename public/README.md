# public/

Static assets served directly by Next.js. Files here are accessible at the root URL path.

## Directories

| Directory | Description |
| --- | --- |
| `images/` | Project screenshots, favicons and Open Graph images |
| `resume/` | CV HTML source files, generated PDFs, DOCX files and cover letters |
| `documents/` | Any other downloadable documents |
| `Media/` | Additional media assets |

## Key files

| File | Description |
| --- | --- |
| `robots.txt` | Search engine crawl rules |
| `_headers` | Cloudflare custom response headers (security headers, cache rules) |

See [public/resume/README.md](resume/README.md) for the full CV system explanation.
