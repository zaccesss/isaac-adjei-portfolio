# hooks/

Custom React hooks used across the portfolio.

## Hooks

| Hook | File | Description |
| --- | --- | --- |
| `useCommandMenu` | `useCommandMenu.ts` | Opens and closes the global command palette |
| `useDashboardShortcuts` | `useDashboardShortcuts.ts` | Keyboard shortcuts for dashboard navigation |
| `useMediaQuery` | `useMediaQuery.ts` | Reactive media query - returns true/false for a CSS breakpoint |
| `useModKey` | `useModKey.ts` | Detects whether the platform modifier key is Cmd (Mac) or Ctrl (Windows/Linux) |
| `useScrollPosition` | `useScrollPosition.ts` | Tracks scroll Y position - used for header shadow and reading progress bar |
| `useTheme` | `useTheme.ts` | Theme (light/dark/system) with Supabase persistence for dashboard users |
