No em dashes or en dashes in code comments or written output - use hyphens or rephrase.

No Oxford commas.

UK English spelling (e.g. "initialised" not "initialized", "colour" not "color" in prose).

Code comments should be first person where possible (e.g. "I drive the animation..." not "This drives the animation...").

**Why:** User preference stated explicitly.

**How to apply:** All code comments, commit messages and written responses in this project.
