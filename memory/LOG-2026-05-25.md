**SECTION B: Migration (ALTER TABLE)**
- B.1 Adds updated_at to goals (weekly digest needs this)
- B.2 Adds hidden, pinned, locked to diary
- B.3 Adds hidden to notes
- B.4 Adds hidden, locked to vault
- B.5 Fixes applications.url unique index
- B.6 Creates new tables: activity_log, habits, habit_logs + RLS + policies
- B.7 Inserts theme_preference config key

### Why CASCADE in DROP TABLE?
PostgreSQL syntax. Drops dependent objects (foreign keys, views) automatically.
IDE shows red errors because it uses T-SQL linting which doesn't know CASCADE.
Supabase uses PostgreSQL - CASCADE is standard and required.
